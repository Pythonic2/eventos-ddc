# Especificações SDD

Crie uma pasta por feature: `specs/NNN-nome-curto/`, com `spec.md`, `plan.md` e `tasks.md` a partir de `_templates/`. Para mudanças pequenas, use apenas critérios no chat; para médias, uma mini-spec; para alto risco, os três documentos e testes rastreáveis.

Se instalar o Spec Kit oficial, preserve a estrutura `.specify/` e os templates gerados por ele. Estas specs são alternativas complementares, não substituem comandos internos do Spec Kit.
